# 주식 양도소득세 계산기

한국 세법에 맞춘 주식 양도소득세 계산기입니다.

## 기능

### 입력 항목
- **기본 정보**
  - 대주주 여부 (대주주/대주주 외)
  - 기업 구분 (중소기업/중소기업 외)
  - 상장 여부 (상장/비상장)

- **양도 정보**
  - 양도일자
  - 양도주식 수
  - 주당 양도가액
  - 양도가액 (자동 계산)

- **취득 정보**
  - 취득일자
  - 취득주식 수
  - 주당 취득가액
  - 취득가액 (자동 계산)

- **필요경비**
  - 증권거래세 (양도가액 × 0.35% 자동 계산)
  - 그 외 필요경비
  - 필요경비 합계 (자동 계산)

- **공제 및 과세**
  - 양도차익 (자동 계산)
  - 기본공제 250만원 적용 여부
  - 과세표준 (자동 계산)

### 세율표

1. **대주주 - 중소기업**
   - 과표 3억 이하: 20%
   - 과표 3억 초과: 25% (누진공제 1,500만원)

2. **대주주 - 중소기업 외 - 1년 이상 보유**
   - 과표 3억 이하: 20%
   - 과표 3억 초과: 25% (누진공제 1,500만원)

3. **대주주 - 중소기업 외 - 1년 미만 보유**
   - 30% 단일세율

4. **대주주 외 - 중소기업**
   - 10% 단일세율

5. **대주주 외 - 중소기업 외**
   - 20% 단일세율

### 계산 결과
- 적용 세율
- 양도소득세
- 지방소득세 (양도소득세의 10%)
- 합계 세액

## 사용 방법

1. 웹 브라우저에서 `index.html` 파일을 엽니다
2. 필요한 정보를 입력합니다
3. "계산하기" 버튼을 클릭하거나 Enter 키를 누릅니다
4. 계산 결과를 확인합니다

## 파일 구성

- `index.html`: 메인 HTML 파일
- `styles.css`: 스타일시트
- `calculator.js`: 계산 로직

## 기술 스택

- HTML5
- CSS3
- Vanilla JavaScript (외부 라이브러리 불필요)

## 특징

- 반응형 디자인으로 모바일에서도 사용 가능
- 실시간 자동 계산으로 편리한 사용성
- 직관적인 UI/UX
- 외부 의존성 없음 (순수 HTML/CSS/JS)

## 주의사항

이 계산기는 참고용으로 제공되며, 실제 세금 납부 시에는 반드시 세무 전문가와 상담하시기 바랍니다.
